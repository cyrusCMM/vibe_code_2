# Product Showcase Gallery

A beginner-friendly GOMYCODE checkpoint built with plain HTML, CSS and JavaScript.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Test manually
1. Confirm three product cards are visible.
2. Click `Dark mode` and confirm the page colors change.
3. Click `Light mode` and confirm the original colors return.
4. Hover over each card and confirm it rises slightly.
5. Reload the page and confirm the cards fade into view.
6. Click a `View details` button and confirm a selection message appears.
7. Narrow the browser window and confirm the cards stack on mobile.

## Push to GitHub
Create an empty repository on GitHub, then in the project folder run:

```bash
git init
git add .
git commit -m "Build product showcase gallery"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

Replace `YOUR_USERNAME` and `YOUR_REPOSITORY` with your real values.
